# 🐼 Panda Runner (Панда Раннер)

Браузерна гра в стилі знаменитого **Google Chrome T-Rex Dino Runner**, але з чарівною **пандочкою** у мальовничому бамбуковому лісі!

---

## 🎮 Як запустити

1. Просто відкрийте файл index.html у будь-якому браузері (Chrome, Edge, Firefox, Opera, Safari):
   - Можна двічі клацнути на index.html у провіднику Windows, або
   - Відкрити консоль у папці D:\Grav та виконати: start index.html

---

## 🕹️ Керування

| Клавіша | Дія | Опис |
| :--- | :--- | :--- |
| <kbd>Пробіл</kbd> / <kbd>↑</kbd> / <kbd>W</kbd> | **Стрибок** | Чим довше тримаєте, тим вище стрибає панда! |
| <kbd>↓</kbd> / <kbd>S</kbd> | **Присісти / Перекат** | Дозволяє прокотитися під високими перешкодами або швидко приземлитися у повітрі |
| <kbd>P</kbd> | **Пауза** | Зупинити або відновити гру |
| <kbd>M</kbd> | **Звук** | Увімкнути / вимкнути 8-бітні звукові ефекти |
| <kbd>R</kbd> | **Рестарт** | Швидкий перезапуск після програшу |
| **Екранні кнопки** | **Сенсорне керування** | Для телефонів і планшетів (кнопки Стрибок та Присісти) |

---

## ✨ Особливості гри

- 🐼 **Жива анімація панди**: кумедний біг, підстрибування вушок, кліпання очима, пил від лапок, згортання в клубочок при присіданні та кумедна реакція при зіткненні.
- 🎋 **Різноманітні перешкоди**:
  - Маленькі та високі бамбукові пагони
  - Бамбукові хащі (кластери з кількох стовбурів)
  - Вкриті мохом камені
  - **Японські журавлі**: літають на 3 висотах (низько — треба перестрибнути, на рівні голови — обов'язково треба присісти/прокотитися, високо — можна безпечно пробігти).
- ⭐ **Бонуси**: золоті паростки бамбука, що дають **+100 додаткових балів** та сяючі іскри!
- 🌅 **Динамічна зміна дня і ночі**:
  - День змінюється заходом сонця, зоряною ніччю з місяцем і ранковим світанком кожні 700 очок.
- 🔊 **Вбудований звуковий синтезатор (Web Audio API)**:
  - Автентичні ретро-звуки без потреби завантажувати аудіофайли.
  - Легендарний подвійний сигнал кожні 100 набраних очок (як у Chrome Dino)!
- 🏆 **Збереження рекорду**: найкращий результат автоматично зберігається у пам'яті браузера (localStorage).
- 📱 **Повна адаптивність**: працює на комп'ютерах, ноутбуках, планшетах та смартфонах.
