# 🐼 Panda Runner (Панда Раннер)

Браузерна гра в стилі знаменитого **Google Chrome T-Rex Dino Runner**, але з чарівною **пандочкою** у мальовничому бамбуковому лісі!

---

## 🎮 Як запустити

1. Просто відкрийте файл index.html у будь-якому браузері (Chrome, Edge, Firefox, Opera, Safari):
   - Можна двічі клацнути на index.html у провіднику Windows, або
   - Відкрити консоль у папці D:\Grav та виконати: start index.html

---

## 🕹️ Керування

| Клавіша | Дія | Опис |
| :--- | :--- | :--- |
| <kbd>Пробіл</kbd> / <kbd>↑</kbd> / <kbd>W</kbd> | **Стрибок** | Чим довше тримаєте, тим вище стрибає панда! |
| <kbd>↓</kbd> / <kbd>S</kbd> | **Присісти / Перекат** | Дозволяє прокотитися під високими перешкодами або швидко приземлитися у повітрі |
| <kbd>P</kbd> | **Пауза** | Зупинити або відновити гру |
| <kbd>M</kbd> | **Звук та музика** | Увімкнути / вимкнути 8-бітну фонову музику та звукові ефекти |
| <kbd>R</kbd> | **Рестарт** | Швидкий перезапуск після програшу |
| **Екранні кнопки** | **Сенсорне керування** | Для телефонів і планшетів (кнопки Стрибок та Присісти) |

## ✨ Особливості гри

- 🐼 **Жива анімація панди**: кумедний біг, підстрибування вушок, кліпання очима, пил від лапок, згортання в клубочок при присіданні та кумедна реакція при зіткненні.
- 🎋 **Різноманітні перешкоди**:
  - Маленькі та високі бамбукові пагони
  - Бамбукові хащі (кластери з кількох стовбурів)
  - Вкриті мохом камені
  - **Японські журавлі**: літають на 3 висотах (низько — треба перестрибнути, на рівні голови — обов'язково треба присісти/прокотитися, високо — можна безпечно пробігти).
- 🛡️ **Суперздібності та бафи**:
  - **Бамбуковий щит (Bamboo Shield)**: рідкісний бонус, що покриває панду сяючою енергетичною сферою, поглинає 1 удар перешкоди та дарує 1 секунду повної невразливості!
- ⭐ **Бонуси**:
  - Золоті паростки бамбука, що дають **+100 додаткових балів** та яскраві іскри.
- 🌅 **Динамічна зміна дня і ночі**:
  - День змінюється заходом сонця, зоряною ніччю з місяцем і ранковим світанком кожні 700 очок.
- 🎶 **Процедурний саундтрек та аудіосинтезатор (Web Audio API)**:
  - Автентична 8-бітна східна пентатонічна фонова мелодія, що **динамічно прискорюється** разом зі зростанням швидкості гри.
  - Поліфонія з ведучою мелодією, ретро-басом і хай-хет бітом.
  - Звукові ефекти стрибка, підкату, дзвінкого підбору щита, тріску ламаного бамбука та бонусів.
  - Жодних зовнішніх аудіофайлів (.mp3/.wav) — усе генерується на льоту!
- 🏆 **Збереження рекорду та налаштувань**: найкращий рахунок і режим звуку автоматично зберігаються у браузері (`localStorage`).
- 📱 **Повна адаптивність**: оптимізовано для ПК, ноутбуків, планшетів і мобільних пристроїв.

## 📝 Останні оновлення (Changelog)

### 🚀 Версія 1.2 — «Shield & Melody Update»
- 🛡️ **Додано суперздібність «Бамбуковий щит»**:
  - Створено новий колекційний предмет щита з векторним відмальовуванням на Canvas.
  - Захисна сфера навколо панди з пульсацією, енергетичними дугами та орбітальними листочками.
  - Механіка поглинання удару з 1 секундою пост-зіткнення для безпечного подолання перешкод.
  - Система частинок: розліт уламків бамбука (`splinter`) та іскри при розбитті.
  - Процедурний кришталевий дзвін активації та реалістичний тріск ламаного бамбука.
  - Індикатор активності щита (`🛡️ ЩИТ`) на панелі HUD.
- 🎶 **Додано процедурну 8-бітну фонову музику (BGM)**:
  - 32-крокова східна мелодія на базі мінорної пентатоніки (лад Юй).
  - Динамічне масштабування темпу від 120 BPM до ~220 BPM синхронно з розгоном гри.
  - Автоматична синхронізація зі станами гри (старт, пауза `P`, екран Game Over, перезапуск `R`).
  - Миттєве безшумне перемикання звуку клавішею `M` або кнопкою 🔊.
